# PRD: HRIS & Payroll Web Application

## Product Overview

A SaaS multi-tenant Human Resource Information System (HRIS) with integrated Payroll engine, tailored for Indonesian companies. Admin & HR dashboard only — no employee self-service.

- **Target Region:** Indonesia
- **Compliance:** PPh 21, BPJS Ketenagakerjaan, BPJS Kesehatan, THR, PPN
- **Platform:** Web application (desktop-first, responsive)
- **Architecture:** SaaS Multi-tenant
- **Tech Stack:** Next.js 15 (frontend) + NestJS 11 (backend) + PostgreSQL + Redis

## Target Users

| Role | Description |
|------|-------------|
| Super Admin | Platform-level admin, manages tenants |
| HR Admin | Manage employees, departments, attendance, leave |
| Payroll Admin | Process payroll, generate payslips, tax filings |
| Finance Admin | View payroll reports, reconcile with accounting |
| Company Admin | Full company-level access |

## Core Modules

### 1. Organization Management
- Multi-company (tenant) support
- Company profile (NPWP, BPJS registration, address)
- Department / Division hierarchy
- Branch / Location management
- Cost center management
- Work schedule configuration

### 2. Employee Management
- Employee master data: personal info, contact, address, NPWP
- Employment details: hire date, employment type (permanent/contract/intern)
- Job title, grade, department, manager assignment
- Salary & compensation structure
- Bank account details for payroll disbursement
- Document uploads (KTP, KK, NPWP, employment contract)
- Employment history & termination workflow
- Family/dependent data (for PTKP PPh 21)

### 3. Attendance & Time Tracking
- Shift definition (regular, night, weekend)
- Daily attendance records (check-in/check-out)
- Overtime calculation (1.5x, 2x, 3x per UU Cipta Kerja)
- Late arrival / early departure tracking
- Integration with payroll for overtime pay

### 4. Leave Management
- Leave types: Annual, Sick, Maternity, Marriage, Bereavement, Unpaid
- Leave balance per employee (quota tracking)
- Leave request creation by HR/Admin
- Leave approval workflow
- Leave calendar view

### 5. Payroll Engine
- Pay period management (monthly, bi-weekly, weekly)
- Salary components: base salary, allowances, overtime, bonuses
- Deductions: absences, late penalties, loan repayments
- Payroll processing workflow (draft → calculated → approved → paid)
- Multi-pay-frequency support
- Retroactive pay adjustments

### 6. Indonesia Payroll Compliance
- **PPh 21**: Progressive tax brackets, PTKP (non-taxable income), TER (effective rate)
- **BPJS Ketenagakerjaan**: JKK (0.24%-1.74%), JKM (0.3%), JHT (3.7% employer + 2% employee), JP (2% employer + 1% employee)
- **BPJS Kesehatan**: 4% (employer) + 1% (employee), salary cap
- **THR**: Religious holiday allowance calculation
- **PPN**: Not directly payroll but available as configurable deduction

### 7. Compensation & Benefits
- Salary structures (grade-based pay scales)
- Recurring allowances (transport, meal, housing)
- One-time bonuses (performance, signing, retention)
- Benefit plans (health insurance, pension)
- Employer contributions tracking (BPJS employer portion)

### 8. Payslip Generation
- Digital payslip per employee per pay period
- Gross pay breakdown (base + allowances + overtime + bonuses)
- Deduction breakdown (BPJS employee, PPh 21, absences, loans)
- Net pay calculation
- Year-to-date summaries
- PDF export

### 9. Reporting & Analytics
- Monthly payroll summary (per department, per company)
- PPh 21 tax report (Form 1721-A1)
- BPJS contribution report
- Headcount & turnover reports
- Payroll cost allocation by cost center
- Audit trail (all payroll changes)

### 10. User & Role Management
- RBAC with granular permissions
- Tenant-level user management
- JWT-based authentication
- Login history & audit logging

## Data Models

Based on Context7 reference schemas (Unified.to HRIS, StackOne, Gusto):

- **Company** — id, name, npwp, bpjs_tk_reg, bpjs_kes_reg, address, phone, email, industry
- **Department** — id, company_id, name, parent_id, manager_id
- **Branch/Location** — id, company_id, name, address, type (HO/branch)
- **CostCenter** — id, company_id, name, code
- **Employee** — id, company_id, employee_number, first_name, last_name, email, phone, gender, dob, marital_status, npwp, bpjs_tk_no, bpjs_kes_no, hire_date, termination_date, employment_type, employment_status, department_id, job_title, grade_id, manager_id, bank_name, bank_account, bank_holder
- **EmployeeDependent** — id, employee_id, name, relationship, dob, id_number (for PTKP)
- **Employer** — JKK, JKM, JHT, JP
- **SalaryStructure** — id, company_id, grade_id, base_salary_min, base_salary_max
- **EmployeeSalary** — id, employee_id, base_salary, effective_date, end_date
- **Allowance** — id, employee_id, name, amount, type (fixed/percentage), frequency, taxable
- **Deduction** — id, employee_id, name, amount, type (fixed/percentage), frequency
- **PaySchedule** — id, company_id, name, frequency, pay_day, cutoff_day
- **PayPeriod** — id, pay_schedule_id, start_date, end_date, status
- **Payroll** — id, company_id, pay_period_id, status (draft/calculated/approved/paid), gross_total, deduction_total, net_total, processed_at, approved_at, paid_at
- **PayrollDetail** — id, payroll_id, employee_id, base_salary, total_allowances, total_overtime, bonus, bpjs_tk_emp, bpjs_kes_emp, jht_emp, jp_emp, pph21, other_deductions, net_pay
- **Payslip** — id, payroll_id, employee_id, generated_at, pdf_url
- **LeaveType** — id, company_id, name, default_quota, is_paid, requires_attachment
- **LeaveBalance** — id, employee_id, leave_type_id, year, total_quota, used, remaining
- **LeaveRequest** — id, employee_id, leave_type_id, start_date, end_date, duration, reason, status, approved_by
- **Attendance** — id, employee_id, date, shift_id, check_in, check_out, status (present/late/absent/half_day), overtime_hours
- **Shift** — id, company_id, name, start_time, end_time, is_overnight
- **TaxConfig** — id, year, ptkp_category, ptkp_amount, bracket_min, bracket_max, rate (progressive)
- **BpjsConfig** — id, year, type (tk/kes), component (jkk/jkm/jht/jp), employer_rate, employee_rate, max_salary_cap
- **User** — id, company_id (null for super), email, password_hash, role, is_active, last_login
- **AuditLog** — id, company_id, user_id, action, entity_type, entity_id, old_values, new_values, timestamp

## API Design

RESTful API with NestJS:
- `/api/v1/auth/*` — Authentication endpoints
- `/api/v1/companies/*` — Company/tenant management
- `/api/v1/employees/*` — Employee CRUD + bulk import
- `/api/v1/departments/*` — Department/org structure
- `/api/v1/attendance/*` — Attendance records
- `/api/v1/leave/*` — Leave requests & balances
- `/api/v1/payroll/*` — Payroll processing
- `/api/v1/payslips/*` — Payslip generation
- `/api/v1/reports/*` — Reports
- `/api/v1/admin/*` — Platform admin (tenants, users)

All endpoints: pagination (`?page=1&limit=25`), filtering, sorting, field selection.
Tenant context via `X-Tenant-ID` header or JWT claim.
